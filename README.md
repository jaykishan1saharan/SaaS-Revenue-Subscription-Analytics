# SaaS Revenue & Subscription Analytics

## Project Overview

This project focuses on analysing SaaS subscription performance, recurring revenue, customer churn, retention, and billing behaviour using Python, SQL, PostgreSQL, and Power BI.

The analysis aims to transform raw subscription and billing data into meaningful business insights that can support data-driven decision-making.

## Objectives

- Analyse Monthly Recurring Revenue (MRR).
- Understand subscription and revenue trends.
- Measure customer churn and retention.
- Perform customer cohort analysis.
- Evaluate invoice and payment performance.
- Identify important business trends and opportunities.

## Technology Stack

- Python
- Pandas and NumPy
- PostgreSQL
- SQL
- Matplotlib and Seaborn
- Power BI
- Git and GitHub
